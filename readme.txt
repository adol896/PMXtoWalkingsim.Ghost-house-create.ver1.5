PMX・VMDマルチスタジオ：著作権・規約およびGLBエクスポート注意点まとめ

​本ドキュメントは、「PMX 3Dマルチキャラ & VMDモーションスタジオ」（pmx_3d.html）の利用および、内蔵されているGLBエクスポート機能を活用するにあたって、把握しておくべき著作権法・各種利用規約・実務上の注意点をまとめたものです。

​1. アプリケーションの基本スタンスと著作権

​本スタジオツールは、サーバー側に他者の著作物（特定のMMDモデルやモーションファイル）を違法に内蔵・再配布・ホスティングしているわけではありません。

​クライアントサイド処理: ユーザーが自身のローカル環境からドロップ、または選択したファイルは、すべてブラウザのメモリ内（Blob URL）でのみ一時的に処理されます。外部サーバーへファイルが蓄積・アップロードされることはありません。

​ビューアとしての位置づけ: 本アプリは、ユーザー自身が手持ちのデータをブラウザ上で安全に読み込んで再生・操作するための「クライアントサイド・ビューア／エディター」として設計されています。

​2. ユーザーが持ち込むアセット（PMX / VMD / VPD）に関する注意点

​アプリケーション自体のシステムはクリーンですが、ユーザーがインターネット等からダウンロードして持ち込む個別の素材データには、それぞれの作者が定めた独自の利用規約が存在します。

​個別モデル・モーションの規約遵守: 

​MMDモデル（.pmx, .pmd）やモーション（.vmd, .vpd）には、作者ごとに「商用利用の可否」「R-18表現の制限」「改変の許容範囲」「クレジット表記の義務」などの規約（ReadMe等）が設定されています。 

​規約に違反する形でモデルを持ち込んだり、不適切な利用を行ったりした場合の責任は、すべて利用者（ユーザー）個人に帰属します。

​プライベート利用と公開の切り分け: 

​個人のPCやブラウザ内で個人的に楽しむ範囲（私的利用）であれば多くの制限が免除されますが、画面録画のSNS投稿やパブリックな配信、ツール自体の商用展開を行う場合は、必ず使用するモデル・モーションの配布規約を確認してください。

​3. GLBエクスポート機能（GLTFExporter）における重大な注意点

​本スタジオには、構築したステージや配置した妖怪モブを1つのファイルとして書き出す「お化け屋敷 GLB ファイル出力機能」が備わっています。ここで最も注意すべき点が「派生著作物と再配布の権利」です。

​エクスポートの法的意味: GLTFExporter を用いてシーンを書き出す行為は、技術的に「元データのメッシュやテクスチャを含む、またはそれをベースにした新しい3Dファイル（派生著作物）を生成する行為」に該当します。 

​リスクの具体例: インターネット等からダウンロードした他者制作の「高品質な背景GLBステージ」をアプリに読み込み、そこに自作の妖怪などを配置して「お化け屋敷GLB」として再配布・共有した場合、元のステージの「再配布禁止（Redistribution Prohibited）」や「改変禁止（No Derivatives）」の規約に違反してしまう恐れがあります。 

​安全な運用ガイドライン: 

​エクスポート機能を用いて書き出す背景ステージは、CC0（著作権放棄）の素材、自身がゼロからモデリングしたオリジナル、または商用・改変・再配布が明示的に許可されているアセットに限定してください。

​アプリ内で生成・エクスポートしたGLBファイルは、原則として「個人の創作活動のバックアップ」や「オフラインでの鑑賞・検証」の範囲にとどめることを推奨します。
